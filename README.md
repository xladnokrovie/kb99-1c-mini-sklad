# Проект «Мини-Склад»

## Состав
- **Подсистемы:** Мини-Склад
- **Справочники:** Товары, Контрагенты
- **Документы:** Поступление, Реализация
- **Регистры накопления:** Остатки товаров, Обороты товаров
- **Отчеты:** Обороты по товарам
- **Печатные формы:** Печать накладной (для документа Реализация)

## Запуск из исходников
1. Создать чистую файловую базу без конфигурации.
2. В Конфигураторе выбрать `Конфигурация` -> `Загрузить конфигурацию из файлов...`.
3. Указать папку с исходниками.
4. Обновить конфигурацию базы данных.
